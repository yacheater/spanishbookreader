# Text format (`texts/<id>.json`)

Generated by `python3 tools/build_text.py <id>` from `inputs/<id>.txt` + `inputs/<id>.meta.json`
and the shared lexicon in `lex/`. Never edit by hand — fix the lexicon and rebuild. The same data
is written to `app/data/<id>.js` for the app (a `<script>` file, so the app also opens from disk).

## Top level
```json
{
  "id": "mate",
  "title": "Historia, mitos y secretos del mate",
  "source": { "kind": "url", "ref": "https://…", "retrieved": "2026-10-24", "edited": "…", "input": "inputs/mate.txt" },
  "chapters": [ { "id": "c1", "title": "…", "paragraphs": [ [token, …], … ], "headings": [3, 17] } ],
  "forms":  { "f12": { "lemma": "tomar.v", "analysis": "pretérito imperfecto · ellos/ellas/ustedes", "en": "they used to drink" } },
  "lemmas": { "tomar.v": { "lemma": "tomar", "pos": "v", "posLabel": "verbo", "en": "to drink; to take", "conjugation": {…}, "gerundio": "tomando", "participio": "tomado" } }
}
```
- **Paragraph** = one non-empty line of the input. `headings` = indices of short lines without final
  punctuation (section titles), rendered as headings.
- **Token**: a string (spaces, punctuation, numbers — copied as is) or `[surface, formId]`;
  `formId` is `null` for proper names (no popup).
- **Article** = one chapter; a book gets one chapter per chapter/topic (not used yet).

## Lemma fields by part of speech
| pos | fields |
|---|---|
| `v` | `conjugation`: `presente`, `preterito_indefinido`, `preterito_imperfecto`, `futuro`, `condicional`, `subjuntivo_presente` — 6 forms each (yo, tú, él/ella/usted, nosotros, vosotros, ellos/ellas/ustedes); reflexive verbs include the pronoun. Plus `gerundio`, `participio` |
| `n` | `gender` (`m` / `f` / `m/f`), `article` (`el` / `la`; `el` for *el agua*), `plural` |
| `adj` | `forms`: `m_sg`, `f_sg`, `m_pl`, `f_pl` |
| others | `lemma`, `pos`, `posLabel`, `en` only |

## Verbatim rule
Joining all tokens of each paragraph gives exactly the lines of `source.input` (trailing spaces
ignored). `tools/validate_text.py` fails otherwise — this is how «текст целиком» is checked.
The input itself may be an edited version of the source (scientific articles: references and
methodology trimmed) — the edit is described in `source.edited` and shown under the text.
