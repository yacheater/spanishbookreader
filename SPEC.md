# ТЗ: «Lector», читалка + карточки для испанского (через английский)

## 1. Цель
Читать на испанском настоящие тексты (статьи, книги, тексты на заданную тему) и сразу превращать незнакомые слова в карточки для повторения в стиле Quizlet. Язык-посредник английский. Мой уровень B1–B2.

## 2. Архитектура и стоимость
- **Приложение:** статичная веб-страница (HTML/JS), адаптивная под ноутбук и телефон. Хостинг на GitHub Pages, бесплатно.
- **Обработка текстов:** в Claude Code из личного аккаунта (Claude Pro). Внутри приложения ИИ не вызывается, ключей API нет.
- **Синхронизация прогресса между устройствами:** Supabase, бесплатный тариф, вход по почте и паролю
  (работает и в иконке на экране «Домой»; первый раз — подтверждение почты ссылкой); запасной вариант —
  ссылка для входа из письма (открывается в браузере). Код из письма не используется: чтобы добавить его в
  шаблон письма, Supabase требует свой почтовый сервер. Синхронизируются слова и выражения, папки,
  «знаю», статусы и расписание повторений, место чтения; размер шрифта и тема — у каждого устройства свои.
  Слияние по каждой карточке: побеждает более позднее изменение (в т.ч. удаление); работает и без сети —
  изменения уйдут при следующем подключении. Статус в шапке: synced / saving… / offline / sync error.
- **Тексты** хранятся в закрытой таблице Supabase (видны только после входа) и загружаются туда
  `tools/publish_texts.py`; в публичный репозиторий не попадают — это полные статьи, их нельзя публиковать.
  Без настроенного Supabase приложение работает локально, как раньше.
- **Телефон:** сайт добавляется на экран «Домой» и открывается как приложение (manifest, иконка Ñ).
- **Несколько пользователей (до трёх):** у каждого свой аккаунт, свои тексты, карточки и прогресс. Исходники —
  в `inputs/<имя>/`; любой текст можно выдать ещё кому-то (`"share"` в meta) без повторной обработки.
  Регистрация закрыта; для нового друга владелец ненадолго её включает. Инструкция для друзей — `FRIENDS.md`.
- **Suggest a text:** на вкладке Texts любой пользователь вставляет текст или ссылку либо прикрепляет файл
  **.md / .txt** (Markdown переводится в обычный текст прямо в браузере: заголовки — отдельными строками, ссылки и
  выделение — просто текст, блоки кода и разделители таблиц убираются, строки таблиц и пункты списков — отдельными
  строками; результат виден в поле и его можно поправить; название берётся из первого заголовка); предложение попадает в
  очередь, владелец говорит Claude «обработай очередь», статус виден в приложении (Waiting → In progress → Ready /
  Not added). Тексты песен не обрабатываются (авторские права) — вместо них пишется учебный текст о языке песни.
- **Направление «английский через испанский»** (Ivan; Lisa учит испанский, как владелец): тексты с `"lang": "en"`,
  свой словарь `lex_en/` (английское слово → перевод на **аргентинском испанском**, vos), формы — `tools/english.py`
  (неправильные глаголы, -s/-ed/-ing, мн. число, степени сравнения). Карточка: *go · went · gone*, мн. число;
  выражения включают фразовые глаголы (тип `phrasal`), объяснения грамматики — на испанском. Write / Choose /
  Translate спрашивают и проверяют перевод по-испански; озвучка английская. Интерфейс английский.
- Пошаговая настройка аккаунтов — `SETUP.md`.
- **Аккаунты** (все личные, не корпоративные): Claude Pro, GitHub, Supabase.

## 3. Загрузка контента (через Claude Code)
Команда в духе «обработай `inputs/book.pdf`» или «напиши текст на тему X»:
1. **Источник:** PDF, вставленный текст или тема (тогда Claude пишет текст сам, уровень около B1–B2).
2. **Текст вставляется целиком, как в источнике**, без адаптации, пересказа и сокращений.
   Исключение — **научные статьи**: убираются навигация и блоки библиографии, раздел о методологии
   заменяется коротким пересказом на испанском (вопросы исследования — дословно). Что сокращено,
   пишется под текстом в читалке.
3. **Деление:** книгу делит на главы/темы, только для навигации, внутри главы сохраняется весь текст. Статья остаётся одним фрагментом.
4. **Словарь фрагмента:** для каждой словоформы задаются:
   - перевод на английский с учётом контекста;
   - лемма (инфинитив глагола, ед. ч. м. р. для прилагательных, ед. ч. для существительных);
   - часть речи;
   - для существительных: род, артикль `el/la`, мн. ч.;
   - для прилагательных: формы м/ж, ед/мн;
   - для глаголов: спряжения по 6 лицам в presente, pretérito indefinido, imperfecto, futuro, condicional, subjuntivo presente.
5. Результат сохраняется в `texts/<id>.json` и публикуется через `git push`.
6. **Как это устроено:** общий словарь `lex/` (словоформа → лемма + перевод в контексте) пополняется
   с каждым текстом; разбор формы и таблицы спряжений считает модуль `tools/conjugate.py`, а не ИИ,
   поэтому они не «галлюцинируют». Сборка проверяет, что текст совпадает с источником символ в символ
   и что каждое слово размечено.
7. Сайты с защитой от ботов (cultura.gob.ar, scielo.cl) автоматически не скачиваются — текст вставляется в чат.

## 4. Читалка
- **Язык интерфейса — английский** (без русских вставок); грамматические термины — испанские (presente, pretérito…).
- **Библиотека:** список текстов, у книг раскрываются главы. Запоминается место чтения в каждом тексте.
- **Наведение на ноутбуке / нажатие на телефоне** на слово открывает всплывающее окно: форма → лемма, перевод на английский, 🔊, кнопки **«+ Learn»** / **«I know it»**; у сохранённого слова — его статус (New / Learning / Learned) и «Remove».
- **Переименование текста:** ✎ у текста в библиотеке → своё название (только у тебя, синхронизируется между
  устройствами; меняется и название папки текста; пустое поле — вернуть исходное).
- **Удаление текста:** 🗑 у текста в библиотеке → «Delete…» → второе подтверждение «Yes, delete» с галочкой
  «удалить и N сохранённых слов из этого текста» (по умолчанию выключена). Свой текст удаляется из базы; текст,
  которым с тобой поделились, скрывается только у тебя (синхронизируется между устройствами).
- **Vos (аргентинский вариант):** в спряжении presente — строка «vos tenés», плюс imperativo vos («tené»);
  формы на vos в тексте распознаются.
- **Подсветка слов:** «учу» одним цветом, «знаю» без подсветки, новые нейтрально.

**Размер и удобство чтения:**
- Кнопки **A− / A+** в шапке: шрифт примерно от 14 до 32 px, шаг около 2 px. Размер запоминается отдельно для телефона и ноутбука.
- Работают жест масштабирования пальцами на телефоне и Ctrl/Cmd + колесо на ноутбуке, вёрстка при этом не ломается.
- При любом размере текст переносится по ширине экрана, горизонтальной прокрутки нет.
- Межстрочный интервал: обычный / просторный.
- Ширина колонки: узкая для удобного чтения / во весь экран.
- Светлая / тёмная тема, по умолчанию как в системе.
- Всплывающее окно слова и карточки масштабируются вместе со шрифтом.

## 4a. Выражения и грамматические конструкции
- **Находятся автоматически** при обработке текста (Claude размечает, сборка проверяет, что каждое
  вхождение действительно есть в тексте). Вручную выделять не нужно.
- **Три типа:** устойчивые выражения (*de hecho, hoy por hoy*), сочетания слов (*tomar una decisión,
  hacer énfasis* — в тексте могут стоять через слово: «tomaron esta decisión»), грамматические
  конструкции (*hay que + infinitivo, llevar + gerundio, para que + subjuntivo, se impersonal*).
  Простые связки и составные предлоги (*sin embargo, debido a, acerca de*) не выделяются.
- **В читалке всегда подчёркнуты:** выражение — сплошной линией, сочетание — пунктиром, конструкция — точками;
  сохранённые — жирнее, другим цветом. Нажатие или наведение на любое слово выражения подсвечивает его целиком;
  в окне сверху блок выражения (тип, значение, для конструкций — объяснение на английском, «+ Learn phrase /
  construction»), ниже — само слово, как раньше.
- **Учатся как слова**, в тех же папках и режимах: Write — написать значение по-английски (засчитывает
  выученным), Choose, Flashcards, In context — вставить выражение / конструкцию в предложение из текста
  (показаны тип, для конструкций — шаблон, значение и число пропущенных слов). У конструкций на карточке —
  объяснение и пример из твоего текста.

## 5. Карточка слова
- Сверху лемма (с артиклем `el/la` для существительных), перевод на английский, 🔊 (Web Speech API, голос es-ES).
- Предложение из текста, где встретилось слово, с выделенной формой.
- Бледным:
  - **глагол:** presente по 6 лицам (yo / tú / él·ella·usted / nosotros / vosotros / ellos·ustedes), ниже сворачиваемая таблица остальных времён;
  - **существительное:** род, артикль, мн. ч.;
  - **прилагательное:** м/ж, ед/мн.

## 6. Вкладка «Words» и папки
- Каждый текст или глава автоматически становится папкой. Свои папки: «+ Folder», переименовать / удалить
  (при удалении слова остаются в других папках).
- Учить можно по одной папке, по нескольким или по всем сразу. **Порядок всегда перемешан.**
- Сверху карточка прогресса по выбранным папкам: «N of M learned», цветная полоса выучено / учу / новые,
  «K due today»; под ней крупная кнопка Review; режимы рядами с иконками (Test — Write, Translate;
  Practice — Flashcards, Choose, In context).
- В библиотеке у текста: метка языка (ES / EN), источник, полоска «выучено из сохранённых», слов · сохранено · выучено.
- Список слов: лемма, перевод, статус; фильтр All / New / Learning / Learned. Нажатие на слово открывает
  карточку целиком (спряжения, пример, история тестов, дата следующего повторения), там же галочки папок
  и «Remove word». Отдельных ссылок «папки / удалить» в строках нет.

## 7. Режимы обучения
**Главное правило: слово считается выученным только после теста Write.** Остальные режимы — практика,
они не меняют статус и расписание.

Статусы: **New** (теста ещё не было) → **Learning** (последний тест не сдан) → **Learned** (последний тест сдан).

**Test (считается):**
- **Write:** испанское слово → пишешь перевод на английский. Засчитывается: любой из вариантов перевода
  из словаря или перевод из текста; опечатка (1 буква в коротком слове, 2 в длинном, перестановка соседних
  букв = 1); другая грамматическая форма (drinking = drink); часть фразы (straw для «drinking straw»).
  Если ответ не принят, а ты считаешь его верным, есть кнопка «I was right».
- **Review:** тот же Write, но только по словам, у которых подошёл срок (интервальное повторение SM-2:
  1 день → 3 дня → ×коэффициент; ошибка — снова через 10 минут, статус Learning).
- Ошибка в сессии → слово ещё раз в конце сессии, но вторая попытка не оценивается.

**Practice (не считается):**
- **Flashcards:** переворот карточки (пробел), «Didn't know / Knew it».
- **Choose:** выбор из 4 вариантов, ES→EN и EN→ES вперемешку, клавиши 1–4. Верный ответ — сразу дальше,
  без повтора того, что уже выбрано; неверный — подсветка правильного и кнопка Next.
- **In context:** пропуск в предложении из текста. Значение показано всегда («means they used to drink»);
  словарная форма и нужная форма («tomar — to drink · pretérito imperfecto · ellos») — в свёрнутом блоке
  «Grammar hint». «First letters» открывает слово по одной букве. Ударения не обязательны, но правильное
  написание показывается.

**Translate (тест):** устойчивые выражения и сочетания из твоих текстов (до 20 за сессию, сначала сохранённые
и ещё не выученные), в обе стороны вперемешку: испанское выражение → английский, английское значение →
испанское выражение (подсказано число слов, «Hint» открывает буквы, «Context» показывает предложение из текста).
Грамматические шаблоны (*hay que + inf.*) не входят — у них нет точного перевода. Проверка без ИИ: варианты
через «/», необязательные части в скобках, опечатки; при ошибке — пословный разбор (другое слово / опечатка /
ударение / пропущено / лишнее) и пример из текста; «+ Learn this phrase» добавляет выражение в карточки;
для сохранённых выражений результат засчитывается как тест.

**Во всех режимах** есть кнопка **End** — закончить досрочно и увидеть итог по уже отвеченным словам.
Enter = Check / Next.

## 8. Вне первой версии
- Адаптация текстов до B1/B2.
- Загрузка текстов прямо из приложения (через личный ключ Claude API).
- Экспорт в Anki.
- Статистика и графики прогресса.

## 9. Порядок разработки
1. Формат JSON + обработка одного тестового текста в Claude Code.
2. Читалка: вывод текста, настройки размера и темы, всплывающее окно слова.
3. Карточки + папки (сначала локально в браузере).
4. Режимы Flashcards / Test / Слово в предложении / интервальные повторения.
5. Supabase (вход + синхронизация) и публикация на GitHub Pages.
6. Проверка на телефоне: нажатия, масштаб, озвучка.

**Статус на 2026-10-24 (v3):** шаг 5 написан и проверен на имитации Supabase (вход, загрузка текстов,
синхронизация двух устройств, работа без сети); ждёт личных аккаунтов GitHub и Supabase (`SETUP.md`).
Шаги 1–4 готовы и проверены в браузере (оба текста, все режимы, папки,
масштаб 14–32 px без горизонтальной прокрутки, наведение и нажатие, тёмная/светлая тема).
Шаг 5 ждёт личных аккаунтов GitHub и Supabase; до него прогресс хранится в браузере
(на телефоне и ноутбуке — отдельно).

## 10. Критерии готовности
- PDF-книга загружается через Claude Code, делится на главы, текст целиком совпадает с оригиналом.
- На любом слове видно лемму, перевод и формы. Слово добавляется в карточки в одно нажатие.
- Слово, добавленное на ноутбуке, через несколько секунд появляется на телефоне.
- Все четыре режима работают по выбранным папкам, порядок всегда случайный.
- Шрифт увеличивается до крупного без горизонтальной прокрутки и наложений, на телефоне и на ноутбуке.
