## Продукт: Lector (рабочее название)
Веб-приложение (PWA: открывается в браузере, ставится на экран телефона как приложение) для изучения языка через
чтение настоящих текстов + карточки. Сделано за один день мной (не программист) вместе с ИИ-агентом Claude Code.
Сейчас им пользуюсь я и двое друзей. Сайт: https://yacheater.github.io/spanishbookreader/

### Языковые направления
- Четыре пары: русский → испанский, русский → английский, английский → испанский, испанский → английский
  (испанский — риоплатский вариант, vos). В профиле выбираешь родной и изучаемый язык; интерфейс и переводы —
  на родном.
- Русские переводы делаются по запросу (для текста, у которого есть русскоязычный читатель) — это доп. стоимость
  обработки на каждый язык перевода.
- Общая полка: открытые тексты, доступные всем ученикам языка; остальное — личные тексты пользователя.

### Чтение
- Тексты: статьи, научные статьи, главы книг. Текст хранится дословно (научные статьи — без библиографии,
  методология пересказана). Песни не обрабатываются из-за авторских прав — вместо них пишется учебный текст о
  сленге песни.
- Нажатие / наведение на любое слово → перевод именно в этом контексте, начальная форма (tomaban → tomar,
  went → go), грамматика (время, лицо, число, род), озвучка, «+ Learn» / «I know it».
- Автоматически подчёркнуты устойчивые выражения, сочетания слов, фразовые глаголы и грамматические конструкции
  (de hecho, tomar una decisión, put off, hay que + infinitivo) — с объяснением, их тоже можно учить.
- Размер шрифта, интервал, тёмная/светлая тема; возврат к месту чтения (синхронизируется между устройствами),
  полоска чтения, прогресс «прочитано / выучено» по каждому тексту.

### Учёба
- Карточка слова: перевод, предложение, где встретилось, полное спряжение (включая vos) или go · went · gone,
  формы рода/числа.
- Практика (не влияет на прогресс): Listen (диктант: слово звучит, пишешь), Flashcards, Choose (выбор варианта), In context (вставить слово в
  предложение из текста, подсказка по грамматике по запросу).
- Тесты (только они засчитывают слово выученным): Write в обе стороны (значение ↔ само слово; смешанный режим:
  сначала узнать, потом написать; ударения, род, синонимы из своих карточек; опечатки и близкие варианты
  засчитываются, кнопка «I was right»), Translate (устойчивые выражения в обе стороны, пословный разбор
  ошибок: другое слово / опечатка / ударение / пропущено / лишнее), Review (интервальное повторение SM-2).
- Папки (по тексту и свои), статусы New / Learning / Learned + отдельный список ошибок (снимается двумя
  верными ответами подряд); учить можно по папке × статусу × ошибкам.
- Короткие сессии (10 / 20 слов, сначала слабые), итог с ошибками сессии; цель 10 ответов в день и серия дней.
- Всё проверяется детерминированно, без ИИ во время использования.

### Аккаунты и контент
- У каждого пользователя свой аккаунт, свои тексты и прогресс; синхронизация телефон ↔ ноутбук.
- Тексты можно выдавать другим аккаунтам без повторной обработки.
- «Suggest a text»: пользователь вставляет текст / ссылку / файл .md или .txt → очередь → я обрабатываю →
  текст появляется у него со статусом Ready. Свой текст можно переименовать, удалить (двойное подтверждение).

### Как устроено и сколько стоит сейчас
- Сайт: GitHub Pages (бесплатно). База и вход: Supabase, бесплатный тариф (хватает на десятки пользователей;
  у бесплатного проекта есть лимиты и пауза при долгом простое).
- Обработка текста (разметка каждого слова, выражений, грамматики) делается вручную через Claude Code — по моей
  подписке Claude. Это узкое место: не масштабируется без автоматизации через платный API.
  Порядок затрат: две научные статьи (~13 000 слов, ~2 500 новых для словаря словоформ) ≈ 1,2 млн токенов
  работы ИИ-агентов. Короткие тексты дешевле.
- Важное свойство: словарь общий и растёт. Каждый новый текст размечается дешевле, слова переиспользуются
  между пользователями. Спряжения и формы считает собственный детерминированный модуль, а не ИИ (не
  «галлюцинирует», бесплатен в работе).
- В приложении нет ИИ во время использования → предельная стоимость одного активного пользователя почти нулевая;
  вся стоимость — в обработке новых текстов.

### Ограничения и открытые вопросы
- Тексты пользователей — чужие статьи: хранятся закрыто, только у загрузившего. Публичная библиотека для
  продажи потребовала бы лицензированного, общедоступного или CC-контента.
- Обработку новых текстов пока делаю я (ручной шаг).
- Нет нативного приложения в сторах, только PWA.
- Продукт создан с помощью ИИ-агента в рабочем аккаунте — нужно проверить, кому принадлежат права на код
  (условия моего трудового договора), прежде чем что-то продавать.
